# Retail Sales Analysis and Prediction

## Project Overview

This project focuses on analyzing retail sales data to understand sales patterns, customer behavior, product performance, and important business trends using Python and Machine Learning.

The project includes data cleaning, exploratory data analysis, statistical analysis, data visualization, and sales prediction.

## Objectives

* Analyze overall retail sales performance
* Understand product and category-wise sales
* Identify monthly and seasonal sales trends
* Analyze customer purchasing behavior
* Study gender-wise sales patterns
* Identify top-performing products and customers
* Understand relationships between numerical variables
* Build a machine learning model to predict sales

## Machine Learning

A machine learning model was developed to predict sales based on the available features.

### Model Evaluation

The model achieved the following results:

* **Mean Absolute Error (MAE):** 159.15
* **Root Mean Squared Error (RMSE):** 287.11
* **R² Score:** 0.9963

The high R² score indicates that the model explains a large proportion of the variation in the target sales values.

## Business Insights
