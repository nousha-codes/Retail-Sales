# Retail Sales Analysis and Prediction

## Project Overview

This project analyzes retail sales data to understand sales patterns, customer behavior, product performance, and business performance using Python and Machine Learning.

## Objectives

- Analyze retail sales data
- Perform data cleaning
- Perform statistical analysis
- Conduct extensive Exploratory Data Analysis
- Identify important business insights
- Predict sales using Machine Learning
- Compare regression models

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Exploratory Data Analysis

The project includes:

- Mean, Median and Mode
- Variance and Standard Deviation
- Quartiles and IQR
- Sales and Profit analysis
- Category analysis
- Product analysis
- Store and City analysis
- Regional analysis
- Customer analysis
- Payment mode analysis
- Monthly and yearly trends
- Outlier analysis
- Correlation analysis

## Machine Learning

Two regression models were implemented:

1. Linear Regression
2. Random Forest Regression

## Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Business Insights

The analysis helps understand the relationship between sales, profit, products, customers, discounts, locations, and other business factors.

## Conclusion

This project demonstrates how data analysis, visualization, statistical techniques, and machine learning can be combined to analyze retail performance and support data-driven business decisions.
